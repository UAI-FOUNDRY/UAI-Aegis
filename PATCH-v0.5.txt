UAI Aegis patch v0.4 -> v0.5
============================
New: live push for the professor's monitor (WebSocket) and function questions
(LeetCode style). No database changes.

HOW TO APPLY
1. Unzip and copy the "uai-aegis" folder over your project folder
   (C:\Projects\UAI aegis\uai-aegis). Say "Replace" when Windows asks.
2. In backend\ with the environment active:
     pip install -r requirements-dev.txt
     python -m app.cli demo-data        (adds the new DSA demo lab; the rest is kept)
3. Restart the server:  uvicorn app.main:app --reload
4. Check it:            python -m app.cli simulate
   (now 4 labs, including "live monitor showed student 3's lock in ... ms")
